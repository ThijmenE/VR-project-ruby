# VR Project Ruby

## Over de game:

In deze game kan de speler een virtuele kamer ontdekken en verschillende activiteiten uitvoeren.

In de kamer zijn verschillende interactieve objecten en minigames te vinden. De speler kan bijvoorbeeld basketballen, bowlen, darten en spelen met bouwblokken. Daarnaast kan de speler een eigen robot in elkaar zetten. Zodra de robot klaar is, komt hij tot leven en reageert hij op de activiteiten van de speler.

## Besturing

De game wordt gespeeld met een VR-headset en twee controllers.

| Actie       | Toets / Knop | Platform |
| ----------- | ------------ | -------- |
| Bewegen     | Linker joystick | VR    |
| Springen    | A knop       | VR       |
| Draaien     | Rechter joystick | VR   |
| Knijpen     | Trigger button links en rechts | VR |
| Oppakken    | Grip button links en rechts | VR |
| Menu        | Menu button | VR        |

## Gameplay

Wanneer je de game opstart, kom je terecht in een virtuele kamer. Hier kun je vrij rondlopen en verschillende activiteiten ontdekken.

Er zijn meerdere dingen die je kunt doen:

Robot bouwen: Zet verschillende onderdelen in elkaar om je eigen robot te maken.

Basketbal: Pak een basketbal en probeer punten te scoren.

Bowlen: Gebruik de bowlingbal om kegels om te gooien.

Darten: Gebruik de dartpijlen om punten te scoren.

Interactieve objecten: Ontdek en gebruik de verschillende objecten in de kamer.

De robot kan reageren op de activiteiten die je uitvoert. Hierdoor krijg je tijdens het spelen feedback op je acties.

## Doel van het project

Het doel van VR Project Ruby is om jongeren op een leuke en toegankelijke manier kennis te laten maken met Virtual Reality. Door middel van eenvoudige besturing, interactieve objecten en verschillende minigames kunnen spelers zelf ontdekken wat VR te bieden heeft.
